# LegalMind-Arbitration

本仓库用于 **LegalMind Arbitration（法律仲裁智能工作台）** 的原型与相关资料沉淀。

## 目录结构

- `Prototype/`：主要原型（React + TypeScript + Vite）
- `docs/`：项目与技术文档
- `prompts/`、`rules/`、`resource/`：提示词/规则/资源等辅助资料

## 快速开始（Prototype）

1. 进入原型目录：
   ```bash
   cd Prototype
   ```
2. 安装依赖：
   ```bash
   npm install
   ```
3. 启动开发服务器：
   ```bash
   npm run dev
   ```

更完整说明请查看：`Prototype/README.md`。
