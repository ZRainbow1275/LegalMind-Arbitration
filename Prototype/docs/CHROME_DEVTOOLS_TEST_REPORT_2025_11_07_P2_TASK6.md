**问题描述**:
点击工具栏"更多"按钮后，下拉菜单未正确显示，无法找到"重新查看引导"菜单项。

**复现步骤**:
1. 打开http://localhost:3002/
2. 跳过引导
3. 点击工具栏"更多"按钮
4. 观察菜单

**预期结果**:
- 菜单正确显示
- 包含"帮助"分组
- 包含"重新查看引导"菜单项

**实际结果**:
- 菜单未显示或延迟显示
- 无法找到菜单项

**可能原因**:
1. FloatingToolbar的DropdownMenu组件渲染延迟
2. onRestartTutorial prop未正确传递
3. 菜单项的条件渲染逻辑问题
4. DOM结构或CSS问题导致菜单不可见

**建议修复**:
1. 检查FloatingToolbar的props解构
2. 验证onRestartTutorial是否正确传递到FloatingToolbar
3. 检查DropdownMenu的渲染逻辑
