## 三、P2 Task 6 - 新手引导功能详情

### 3.1 功能概述

实现了完整的新手引导系统，帮助首次使用用户快速了解LegalMind法律工作台的核心功能。

### 3.2 核心特性

1. **自动触发**: 首次使用自动显示引导（1秒延迟）
2. **7步引导流程**:
   - 步骤1: 欢迎页面
   - 步骤2: 创建节点
   - 步骤3: 连接节点
   - 步骤4: 搜索节点
   - 步骤5: 过滤节点
   - 步骤6: 导出/导入数据
   - 步骤7: 完成引导
3. **导航控制**: 上一步、下一步、跳过、完成
4. **键盘快捷键**: Escape、ArrowLeft、ArrowRight、Enter
5. **状态持久化**: localStorage保存引导状态
6. **重新查看**: 工具栏"更多"菜单中的"重新查看引导"选项
