## 🐛 发现的问题和修复

### 问题 1: 过滤摘要持久化显示错误

**问题描述**: 
- 刷新页面后，过滤条件已恢复，但过滤摘要显示"无过滤条件"
- 过滤结果正确，但UI显示不一致

**根本原因**: 
- `isActive` 状态在 persist 恢复时没有重新计算
- `partialize` 只持久化了过滤条件，没有持久化 `isActive`
- 恢复后 `isActive` 保持初始值 `false`

**修复方案**: 
- 在 persist 配置中添加 `onRehydrateStorage` 回调
- 恢复后重新计算 `isActive` 状态
- 确保过滤摘要显示与实际过滤条件一致

**修复文件**: `Prototype/src/stores/filterStore.ts`

**修复代码**:
```typescript
{
  name: 'filter-storage',
  partialize: (state) => ({
    selectedTypes: state.selectedTypes,
    selectedStatuses: state.selectedStatuses,
    timeRange: state.timeRange,
    customTimeRange: state.customTimeRange,
    selectedTags: state.selectedTags,
  }),
  // {{ AURA: Add - 恢复后重新计算isActive状态 }}
  onRehydrateStorage: () => (state) => {
    if (state) {
      const isActive = hasActiveFilters({
        selectedTypes: state.selectedTypes,
        selectedStatuses: state.selectedStatuses,
        timeRange: state.timeRange,
        customTimeRange: state.customTimeRange,
        selectedTags: state.selectedTags,
      });
      state.isActive = isActive;
    }
  },
}
```

**验证结果**: ✅ 修复成功
- 刷新页面后，过滤摘要正确显示"1种类型"
- `isActive` 状态正确恢复为 `true`
- UI显示与实际过滤条件一致
